# Prompts

Prompts are versioned here. One file per version, never edited in place. A new
version gets a new filename so results stay traceable to the exact text that
produced them.

## baseline_v1.txt

The prompt template from the FINDVER paper's own baseline. Two placeholders,
`<REPORT>` and `<STATEMENT>`.

Fill it with `str.replace`, not `str.format`. The template contains a literal
`{entailment_label}` that the model is meant to read, and `.format()` would try
to substitute it and raise `KeyError`.

The required final sentence is `Therefore, the claim is entailed.` or
`Therefore, the claim is refuted.` The label extractor parses that sentence.
Neither local model reliably produced it in week 1 testing, so the extractor
needs regex, paraphrase fallbacks, and an explicit `unparseable` bucket.

## samples/ie-val-0_filled.txt

The same template filled for example `ie-val-0`, using paragraphs 83 to 99 of
`NJR-2024-02-06_10-Q.json`.

Generated by `src/build_prompt.py`, a week 1 script removed in commit `b2e461d`
and recoverable from `bb60f01`. This file is the exact input the week 1
throughput numbers were measured on. See `docs/working_state.md`, section
"Measured performance". Keep it byte identical, otherwise those numbers lose
their referent and cannot be compared against later measurements.
